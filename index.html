Tipps für scanbare Codes

  • ✅ Starker Kontrast zwischen Punkten und Hintergrund.
  • ✅ Mit Logo? Stelle die Fehlerkorrektur auf Hoch (H).
  • ✅ Für Druck SVG oder großes PNG (800px+) exportieren.
  • ✅ Teste immer mit der Handykamera vor der Veröffentlichung.

Häufige Fragen

Ist es wirklich kostenlos?

Ja. Kein Konto, kein Wasserzeichen, keine Limits. Erstellt von der Musaj GmbH.

Laufen meine Codes ab?

Niemals. Das sind statische QR-Codes — die Daten stecken im Code selbst und funktionieren für immer.

Sind meine Daten privat?

Absolut. Alles läuft in deinem Browser. Nichts, was du eingibst, wird auf einen Server geladen.

Darf ich sie kommerziell nutzen?

Auf jeden Fall — auf Verpackungen, Flyern, Menüs, Visitenkarten, überall.
